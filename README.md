# Lan-music-control

一个基于局域网的跨端工具。通过 Android 手机隔空控制 Windows 电脑端的音乐打开或关闭，解决距离电脑远（比如戴着耳机躺在床上或坐在旁边）时不方便操控电脑音乐的真实痛点。
## 💡 项目背景
平时在房间里用 Windows 电脑听歌或看视频，蓝牙耳机连在电脑上。当人离开电脑桌有一段距离时，如果想临时暂停或者开启音乐，就必须特地跑回电脑前操作，非常不方便。市面上没有找到简单、干净、无广告的顺手工具，于是决定自己动手开发一个。

## 🛠️ 项目是如何工作的？
这个项目由两个部分组成，手机和电脑只需要连接在同一个 Wi-Fi（局域网）下即可：

1. **Windows 电脑端（服务端）**：
   - 在电脑后台运行，负责监听手机发来的控制指令。
   - 收到指令后，模拟系统媒体按键来控制音乐的播放与暂停。

2. **Android 手机端（客户端）**：
   - 一个干净的手机 APP 界面。
   - 包含控制按钮，点击后通过无线网络向电脑发送开关指令。

## 📁 源码目录说明
- `/android-app`：Android 手机端原生代码（处理 UI 界面与网络发送）
- `/windows-server`：Windows 电脑端后台程序代码（处理端口监听与系统控制）

## 此项目为第2版本迭代 
第一版本 手机app控制主流媒体播放器电脑端(qq音乐、网易云、汽水音乐) 通过Windows API 拦截全局多媒体虚拟键值（keybd_event / SendMessage）与 UDP 无线异步通信技术 实现
第二版本 整合第一版本控制器，并融入独立音频mp3解码，独立播放器，移除对第三方音乐软件的依赖，集成mp3解码，基本形成独立流媒体播放器
